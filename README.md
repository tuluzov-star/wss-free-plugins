# WSS Free Plugins

Public repository for Free versions of Website Support / WSS WordPress and WooCommerce plugins.

Commercial Pro versions, license manager code, private release archives and customer data are not stored in this repository.

## Plugins

| Plugin | Source path | Website |
|---|---|---|
| Delivery Zones on Map for WooCommerce | `plugins/delivery-zones-free` | https://website-support.ru/plugins/delivery-zones-for-woocommerce/ |
| WSS Order Status Colors for WooCommerce | `plugins/order-status-colors-free` | https://website-support.ru/plugins/order-status-colors-for-woocommerce/ |
| WSS Bookings Schedule Lite | `plugins/bookings-schedule-free` | https://website-support.ru/plugins/wss-bookings-schedule/ |
| WSS Yandex Calendar for WooCommerce Bookings | `plugins/yandex-calendar-sync-free` | https://website-support.ru/plugins/yandex-calendar-for-woocommerce-bookings/ |
| WSS WooCommerce Bookings | `plugins/wss-woocommerce-bookings` | https://website-support.ru/plugins/wss-woocommerce-bookings/ |

Use plugin-specific ZIP files from `releases/.../free/` or from website-support.ru. Do not install the whole repository ZIP as one WordPress plugin.
