# WSS WooCommerce Bookings — Yandex Calendar — Free

Бесплатная версия плагина для односторонней синхронизации официального WooCommerce Bookings в Яндекс.Календарь через CalDAV.

## Возможности Free

- Один Яндекс.Календарь.
- Подключение через CalDAV URL, email и пароль приложения.
- Проверка подключения.
- Отправка новых будущих бронирований, связанных с заказами WooCommerce в статусах `Обработка` и `Выполнен`.
- Базовое создание/обновление события в календаре.
- Корректная передача времени через `TZID`, без смещения UTC.

## Pro-функции

- Первичная синхронизация всех будущих бронирований за сегодня и дальше.
- Настройка статусов заказов.
- Настраиваемые шаблоны заголовка и описания события.
- Пометка отменённых событий префиксом `[ОТМЕНЕНО]` без удаления события.
- Очистка связей booking → Yandex UID.
- Пакетная обработка больших объёмов броней.
- Лицензия и обновления через website-support.ru.

## Настройка

1. Установить и активировать плагин.
2. Открыть `WooCommerce → Yandex Calendar`.
3. Вставить email Яндекса, пароль приложения и CalDAV URL календаря.
4. Нажать `Сохранить настройки`.
5. Нажать `Проверить подключение`.

Пароль приложения хранится в настройках WordPress. Не отправляйте его в переписку и не храните в публичных репозиториях.
