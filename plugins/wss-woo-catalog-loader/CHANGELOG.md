# Changelog

## 1.1.0

- Prepared the plugin for public distribution under GPL-2.0-or-later.
- Added English source strings and bundled Russian localization.
- Added dependency handling and public metadata.
- Added uninstall cleanup.
- Hardened custom selector handling.
- Added an IntersectionObserver fallback.
- Added WooCommerce product-search archive detection.
- Added reduced-motion support for AJAX pagination scrolling.
- Leave Product Collection Block pages untouched until a dedicated tested adapter is available.
- Added public documentation and lifecycle-event examples.

## 1.0.6

- Mobile inherits the main mode by default.
- Separate mobile mode is explicit and opt-in.

## 1.0.5

- Result count can be removed before rendering to avoid a visible flash.

## 1.0.4

- Result-count handling now also works on one-page archives.

## 1.0.3

- Improved duplicated result-count handling.

## 1.0.2

- Infinite Scroll and Load More keep the original browser URL.
- History API is limited to AJAX pagination.

## 1.0.1

- Fixed product-grid deformation from service markers.
- Infinite loading is unlimited by default.

## 1.0.0

- Initial release.
